# MPlayer Adaptive

Лёгкий плеер для Linux на Python / Qt 6 с движком mpv. Это начальная рабочая
реализация: собственная панель управления и отдельное нативное окно mpv.
Встраивания видео в Qt пока нет; такой вариант не зависит от X11 window ID.

## Установка и запуск

Arch Linux (из корня проекта, системным Python):

```sh
sudo pacman -Syu mpv pyside6 pciutils
python -m mplayer
```

Ubuntu (Python 3.10+, mpv с поддержкой `gpu-next`):

```sh
sudo apt update
sudo apt install mpv python3-venv pciutils
python3 -m venv .venv
.venv/bin/pip install .
.venv/bin/mplayer-adaptive
```

Запускайте команды из каталога проекта. На Arch можно передать файл:
`python -m mplayer /path/to/video.mkv`. На Ubuntu используйте
`.venv/bin/mplayer-adaptive /path/to/video.mkv`.

## Возможности

- Открытие файлов и URL, пауза, перемотка, громкость, полный экран.
- Системные данные: GPU через lspci, RAM, число CPU-потоков, тип сеанса,
  наличие mpv. Данные остаются локально.
- Автоматический выбор bilinear / lanczos по доступной информации,
  разрешению видео и экрана, FPS. Неизвестная GPU и тяжёлые режимы получают
  экономичный профиль. Название GPU не используется как бенчмарк.
- После прогрева три последовательных интервала с минимум тремя пропущенными
  кадрами каждый снижают профиль. После перемотки прогрев начинается заново.
  Это эвристика: пропуски могут быть связаны также с декодером или источником.
- Ручные профили, отдельный выбор масштабирования, GLSL/HOOK шейдер,
  аппаратное декодирование, deband в качественном профиле.
- Настройки в `$XDG_CONFIG_HOME/mplayer-adaptive/settings.json`, по умолчанию
  `~/.config/mplayer-adaptive/settings.json`. Кнопка «Применить» сохраняет их.

Масштабирование идёт до размера окна видео, с сохранением пропорций.
При автоматическом выборе размер экрана панели служит приближением к целевому
размеру; на нескольких мониторах он может отличаться от экрана видео.
Ручные настройки вступают в силу после «Применить». В автоматическом режиме
ручной scaler и внешний шейдер игнорируются. Повышение качества после снижения
выполняется при новом видео / реконфигурации или нажатии «Применить».

## Внешние апскейлеры

Где скачать шейдеры:

- [ArtCNN — папка GLSL](https://github.com/Artoriuz/ArtCNN/tree/main/GLSL).
  Для начала можно попробовать лёгкую модель `ArtCNN_C4F16.glsl`:
  откройте файл на GitHub и сохраните через **Raw / Download raw file**.
- [Anime4K — Releases](https://github.com/bloc97/Anime4K/releases).
  Скачайте архив GLSL-шейдеров в разделе **Assets** и распакуйте его.
  Готовые пресеты Anime4K могут требовать цепочку нескольких шейдеров;
  в текущем интерфейсе можно выбрать только один файл.

Сохраните `.glsl` или `.hook`, например, в `~/.config/mpv/shaders/`.
В плеере выберите ручной профиль («Сбалансированный» или «Качественный»),
затем **Шейдер → Выбрать… → Применить**. В автоматическом режиме внешний
шейдер не применяется. Загружайте сам файл шейдера, а не HTML-страницу GitHub.

В ручном режиме можно выбрать совместимый с mpv GLSL-шейдер, например из
[Anime4K](https://github.com/bloc97/Anime4K) или
[ArtCNN](https://github.com/Artoriuz/ArtCNN). Они ориентированы на аниме.
Приложение не скачивает модели и не включает чужой код в дистрибутив.
Сейчас поддерживается один файл; многопроходные цепочки из нескольких файлов
нужно будет добавить отдельно. Производительность и визуальное качество
стороннего шейдера необходимо проверить на своём видео.

Сглаживание mpv — временная интерполяция для синхронизации с дисплеем,
не RIFE и не аналог генерации кадров Lossless Scaling. Интеграция
VapourSynth / RIFE пока не реализована. Автоматический режим не выбирает
нейросетевые модели: для этого нужны обнаружение установленных моделей и
измерение их производительности.

## Внешние аудиодорожки

В строке **Папка аудио** нажмите **Папка…** и выберите каталог с озвучками
для текущего видео. Файлы из него подключатся сразу; имя файла не обязано
совпадать с именем видео. Поддерживаются, в частности, MKA, M4A, AAC, AC3,
EAC3, DTS, FLAC, MP3, OGG, OPUS и WAV. Вложенные папки не просматриваются.

Выберите нужную озвучку в списке **Аудиодорожка**. Там же доступны встроенные
дорожки и вариант «Без звука». Добавление папки сохраняет текущую озвучку,
если она уже выбрана. При смене папки ранее подключённые через неё дорожки
заменяются; встроенные дорожки остаются доступными. Чтобы отключить папку,
очистите поле и нажмите **Применить**.

Путь сохраняется в настройках и используется при открытии следующего видео.
Для сериала выбирайте папку с дорожками именно текущей серии: подключаются
все аудиофайлы в выбранном каталоге. Путь можно также вписать вручную и
нажать **Применить**. Видео не перезапускается при смене папки.

## Диагностика и тесты

Если при запуске появляется `No module named mplayer`, проверьте, что текущий
каталог содержит папку `mplayer` (в нижнем регистре). В Linux `MPlayer` и
`mplayer` — разные имена. В старой версии проекта папка имела неверный регистр;
обновите исходники и повторите запуск из корня проекта.

При ошибке `No module named PySide6` на Arch установите пакет `pyside6` и
запускайте `/usr/bin/python -m mplayer` из корня проекта: обычное виртуальное
окружение не видит пакеты, установленные через pacman.

Вывод mpv отображается в панели. Ошибки применения свойств появляются там же.
Для субтитров, аудиодорожек и дополнительных действий доступны штатные
клавиши и экранное управление mpv в окне видео.

```sh
python -m unittest discover -s tests -v
python -m compileall -q mplayer
```

Тесты проверяют политику выбора и реакцию на пропуски кадров. Полноценную
проверку воспроизведения, аппаратного декодирования, шейдеров и Wayland/X11
нужно проводить в графической Linux-сессии на целевой GPU.

Документация параметров: https://mpv.io/manual/stable/
